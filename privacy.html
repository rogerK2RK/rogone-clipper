Privacy Policy

Last updated: November 17, 2026

1. Everything stays on the user's computer

Rogone Clipper runs locally. Videos, transcriptions, clips and thumbnails are stored only on the user's own computer. The app has no server and no database of its own, and it does not sell, share or analyse personal data.

2. Data received from TikTok

When the user connects their TikTok account, the app receives through TikTok's official APIs:

  • an access token and refresh token, used only to upload the clips the user chooses;
  • basic profile information (open ID, display name, username, avatar) and the account's posting options (available privacy levels, interaction settings, maximum video length), shown so the user knows which account will receive the post.

Tokens are stored in a local file on the user's computer and are never sent anywhere except to TikTok's API.

3. Data sent to TikTok

Only the video file and the post settings (caption, visibility, interaction and disclosure options) that the user explicitly confirms are sent to TikTok.

4. Third parties

Videos the user chooses to download are fetched from the source the user provides. No analytics or advertising services are used.

5. Deleting your data

The user can disconnect TikTok at any time from the app (this deletes the stored tokens) and revoke access in the TikTok app under Settings and privacy › Security › Apps and services. Deleting the app's folders removes all local data.

6. Contact

Questions about this policy can be sent to the developer, Roger Retita, through his TikTok for Developers account.
